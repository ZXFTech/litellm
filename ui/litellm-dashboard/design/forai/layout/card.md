# 卡片布局

适用于普通卡片、设置、预览及卡片型浮层。这是布局模式，不承诺独立组件 API。

## CARD-1 完整内容

卡片及内部区域不出现横向滚动。文本、链接、代码、表格和控件用换行、响应式重排或适配宽度完整展示，不能通过裁掉正文、隐藏操作或仅隐藏滚动条满足规则。

宽度受容器和视口约束，flex / grid 子项按需使用 min-w-0 与 max-w-full。长连续文本允许换行，固定宽度或 whitespace-nowrap 不能撑开卡片。高度受限时可以纵向滚动。

## CARD-2 实际验证

核对常规宽度、窄屏、明暗、三档密度及长连续文本。结合 scrollWidth <= clientWidth 和可见内容检查伪元素、负外边距、扩展点击区域与焦点提示，确认内容没有被裁切。换行后点击、键盘和必要的纵向滚动仍可用。
