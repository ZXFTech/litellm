# 后台全局布局

## 布局骨架

| 区域 | 职责 | 布局与滚动 |
| --- | --- | --- |
| AdminShell | 容纳全局导航和工作区 | 顶栏占一行，工作区占剩余可用高度。 |
| GlobalHeader | 提供产品标识，以及按需提供全局搜索、通知、帮助和用户菜单 | 保持可见，高度 `64px`。窄屏将低频入口归入可访问的菜单。 |
| Sidebar | 用组名、模块、项目名称和当前项定位业务 | 展开 `224px`，折叠 `64px`。导航自身纵向滚动。折叠项保留可访问名称。 |
| Main | 承载当前页的标题、正文和必要操作 | 面包屑显示时独立吸顶。页头随正文纵向滚动，底部操作栏单独占位并贴住主区可视底边。 |
| PageContainer | 统一面包屑、页头、正文和底栏的对齐边界 | 扣除页面两侧留白后再计算内容宽度。按照当前任务选择容器模式。 |

全局搜索处理跨模块查找，列表筛选留在当前页面。全局导航标明当前模块和页面，业务名称简短且稳定。面包屑用于说明模块内有意义的层级，可按需显示。显示时，面包屑在全局顶栏下方独立占位，主区滚动时始终可见。页头随所含标题、描述和操作自然增高。

页面有底部操作栏时，操作栏下缘与主区可视底边重合，正文不足一屏或滚动到末尾时均保持贴底。操作栏按实际高度占位，正文滚动区的可视下界位于操作栏上方。长内容要能将最后一个字段、说明和反馈完整滚动到操作栏上方，键盘焦点及其指示也应完整可见。

## 容器模式

| 模式 | 宽度 | 适用任务 |
| --- | --- | --- |
| Standard | 居中，内容上限 `1200px` | 常规列表、详情与信息概览。 |
| Wide | 保留标准两侧留白，使用其间的全部宽度 | 宽表格及多模块仪表盘。 |
| Focused | 居中，内容上限 `960px` | 表单、字段型设置与向导。 |
| Fullscreen | 使用应用的可用视口，可按任务隐藏全局导航 | 需要持续查看的监控、地图等工作区。提供明确的退出动作，退出后恢复此前的导航和容器状态。 |

## 响应式布局

以外壳实际可用宽度计算档位。独立应用使用当前视口内的外壳宽度，嵌入实例使用自身容器宽度。具体业务区域按自己获得的空间重排。

| 外壳宽度 | 默认侧栏 | 每侧水平留白 | 业务栅格 |
| --- | --- | --- | --- |
| `1600px` 起 | 展开 | `--spacing × 8`，Default 为 `32px` | 12 列基准 |
| `1280px` 至 `1599px` | 展开 | `--spacing × 6`，Default 为 `24px` | 12 列基准 |
| `1024px` 至 `1279px` | 折叠 | `--spacing × 6`，Default 为 `24px` | 12 列基准 |
| `768px` 至 `1023px` | 抽屉，默认关闭 | `--spacing × 4`，Default 为 `16px` | 12 列基准 |
| 小于 `768px` | 抽屉，默认关闭 | `--spacing × 4`，Default 为 `16px` | 业务模块默认单列 |

桌面折叠和展开保留当前导航项及用户任务。窄屏导航入口位于顶栏，打开后焦点进入抽屉，模态背景暂停交互。通过关闭控件或适用的 Escape 退出，焦点返回触发器。按新档位切换导航形态时，当前路由和业务输入继续保留，已失去作用的浮层关闭，焦点转到对应可用位置。

主区小于 `768px` 时业务区域默认单列，先保留标题、主要操作和当前任务的数据。面包屑空间不足时自然换行，按实际高度占位。页头操作和筛选允许自然重排。宽表横向滚动由带可访问名称的表格区域承载，页面根部保持与视口同宽。为正文首尾内容和键盘焦点留出空间，使其能够滚动到顶栏、面包屑和底栏之外的完整可见位置。

## 尺寸与语义 Token

| 设计量 | 来源 | Compact / Default / Comfortable |
| --- | --- | --- |
| `--spacing` | 共享密度单位，复用 `--layout-unit` | `3.5px / 4px / 5px` |
| 基础间距步长 | `--spacing × 2` | `7px / 8px / 10px` |
| 窄档横向留白 | `--layout-page-padding-inline` 的基础语义值 `--spacing × 4` | `14px / 16px / 20px` |
| 中档横向留白 | `--spacing × 6` | `21px / 24px / 30px` |
| 超宽档横向留白 | `--spacing × 8` | `28px / 32px / 40px` |
| 顶部留白 | `--layout-page-padding-block` 的基础语义值 `--spacing × 6` | `21px / 24px / 30px` |
| 模块间距 | `--layout-section-gap` | `21px / 24px / 30px` |
| 栅格间距 | `--spacing × 6` | `21px / 24px / 30px` |

像素换算以根字号 `16px` 为基准。顶栏高度、侧栏轨道、断点和内容上限属于固定结构量。颜色、字体、圆角、控件及密度沿用 [基础规范](../index.md)。实现可用局部变量表达固定结构和断点间距，已有共享语义变量优先。

## 规范等级

| 等级 | 要求 |
| --- | --- |
| MUST | 采用统一布局骨架及固定结构尺寸，按宽度切换导航并明确滚动归属。面包屑显示时须吸顶，底部操作栏显示时须贴住主区可视底边。正文首尾内容、焦点和主要操作须可达。 |
| SHOULD | 根据任务采用 Standard、Wide 或 Focused，沿用密度 Token，优先避免页面级横向滚动。 |
| MAY | 在主任务不受妨碍时增加辅助面板或低频全局入口。 |
| EXCEPTION | 需要整屏的监控、地图或其他特定工作区可使用 Fullscreen，保留退出路径及恢复规则。 |
