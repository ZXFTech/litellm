# 后台通用组件与交互

先按 [页面区域与模板](page-templates.md) 分配任务区域、操作和信息顺序，再选择下列交互。布局约束继承 [全局布局](global-layout.md)，通用控件变体与行为遵循 [组件规范](../components/index.md)。所用组件、属性和能力以项目实际实现为准。同一示例中的状态用可读文字和明确语义区分，颜色与图标同时承担辅助表达。

## C01 数据表格

适用于列表、关联记录和报表明细。数据工具栏、列标题、数据行和分页按读取顺序排列。列标题采用业务名称；同列日期和币种格式一致，数字右对齐。长文本可换行或提供完整内容入口。若需要横向滚动，结果区域保持有名称、可滚动且可用键盘访问。

* **MUST**　可排序列提供可操作的表头与排序方向；选择提供行语义、全选或半选、数量和准确范围。批量操作使用已明确选中的记录。空列表、请求失败、刷新及筛选无匹配分别说明。
* **SHOULD**　选择、排序及行级编辑使用稳定记录 ID。窄区保留识别与操作核心列，工具栏和分页允许换行。
* **MAY**　按权限提供列设置、默认排序、导出或跨页选择。跨页能力明确公布所选范围、变化和结果。
* **EXCEPTION**　持续写入日志可使用连续加载，保留当前浏览范围和暂停方式。

## C02 搜索与筛选

搜索词和常用条件靠近对应结果。条件较多时按业务分组，次要条件可折叠，已生效条件和可用的清除方式保持可见。窄区字段与动作按阅读顺序重排。

* **MUST**　明确即时触发或提交触发。提交型查询区分草稿与已生效条件；查询变更回到第一页，重置恢复声明的默认范围。
* **SHOULD**　重试保留已应用条件；指出没有业务数据或当前条件无匹配，并提供对应的下一步。切换筛选模式时说明触发时机。
* **MAY**　保存常用条件或将已应用条件同步到 URL。只为有真实语义的筛选配置专用控件。
* **EXCEPTION**　角色或组织范围可作为固定条件，说明来源及适用范围。

## C03 表单与字段

字段由持续可见的标签、输入、辅助说明及对应反馈组成。按任务顺序分组，窄区单列，同组短字段可在空间足够时并排。

* **MUST**　关联标签和输入，提供必填、只读、禁用与无效语义。字段问题就近呈现，提交失败保留已填写内容，进行中的提交防止重复触发。
* **SHOULD**　提交后可定位首个待修正字段，未保存修改有清楚提示与继续或放弃的路径。保存和取消集中归属页面操作栏。
* **MAY**　按业务选择异步校验时机、应用初始值或提供有范围说明的草稿。异步结果对应当前输入。
* **EXCEPTION**　低风险配置可自动保存，说明生效时机、反馈和恢复方式。

## C04 按钮与页面操作

按影响范围分配操作，整页、数据集、单条记录和提交操作各自靠近任务。同组动作保留稳定顺序，空间不足时允许换行，将低频动作归入菜单。

* **MUST**　每个操作区清楚表达主操作，图标动作有可访问名称。危险、禁用、加载及失败可感知，危险操作说明对象和后果。
* **SHOULD**　异步操作保持焦点稳定，处理中阻止重复触发，结果反馈按任务影响范围提供。给出用户可理解的禁用原因。
* **MAY**　按权限、业务优先级及频率配置次要动作或菜单。
* **EXCEPTION**　连续处理多条记录时可在各记录保留高频入口，明确作用范围并保持层级一致。

## C05 分页

分页紧跟所属集合，保留当前页、前后页、边界禁用及总数的可读语义。窄区允许控件换行，保留方向与当前位置。

* **MUST**　标明当前页并禁用不可用的方向。修改筛选或页大小时按已知规则定位，删除末页记录后回到仍存在的页。读取失败与已知零条有不同反馈。
* **SHOULD**　页数很多时用有限页码窗口显示边界和当前附近位置，避免把全部页码同时渲染。通过状态文字报告当前位置或数据范围。
* **MAY**　按业务支持每页数量及有校验的跳转输入。无需翻页时简化操作区。
* **EXCEPTION**　游标数据总数未知时，显示已加载范围和仍可读取的方向。

## C06 对话框与确认

用于简短提交、确认或必须先处理的决定。标题、任务内容、结果反馈及主要操作分区明确。长内容在正文内纵向滚动，操作保持可达。

* **MUST**　浮层有可访问名称和明确取消方式。模态打开后焦点进入，背景暂停交互，关闭后焦点返回入口或该入口消失后的合理位置。危险操作说明对象、影响和后果。
* **SHOULD**　危险确认优先聚焦安全选项，长内容可从有语义的标题开始阅读。保留可修正输入，按项目约定支持 Escape。
* **MAY**　根据任务配置外部点击关闭、内容长度及可取消请求。在窄屏保留标题和动作，控件可换行。
* **EXCEPTION**　阻塞故障可阻止外部点击关闭，提供完成、处理或安全退出的路径。

## C07 抽屉

提供返回当前任务的补充视图，例如订单摘要、快速详情或短编辑。标题和显式关闭置于可达位置，长正文在抽屉内滚动。窄屏可按需采用底部或整宽布局。

* **MUST**　保留明确关闭和未保存修改处理。模态抽屉使用与对话框相同的焦点管理、背景约束和焦点归还规则。
* **SHOULD**　抽屉承担短辅助任务，多步或高密度工作使用独立页面。主体滚动时关闭、取消或提交保持可达。
* **MAY**　按空间选择方向、宽度和手势，手势有可用的显式操作替代。
* **EXCEPTION**　全局导航抽屉按外壳导航规则运行；嵌入实例的导航可限定在其实例范围内。

## C08 标签导航

标签用于共享对象或任务中地位并列的内容。名称简短，当前项和面板建立语义关联，面板在标签之后按阅读顺序导航。

* **MUST**　支持主要键盘导航与清楚的激活时机。标签切换保留明确约定的草稿处理，面板局部失败保持对应标签上下文。
* **SHOULD**　即时呈现面板时可自动激活，存在明显读取延迟时优先使用明确激活。长标签行可局部滚动或重排，保持当前项可见。
* **MAY**　按业务配置分类顺序、方向、延迟读取和缓存，受限项提供适当说明。
* **EXCEPTION**　可分享的分类可同步到 URL，继续保持标签语义和前进、返回时的选中状态。

## C09 消息与结果反馈

反馈与产生它的操作或信息区域配对。成功、信息、警告、错误及恢复使用可读文案；涉及字段修正的问题同时关联对应字段。

* **MUST**　下载发起、批量操作完成和重试恢复等一次性回执使用共享 Toast，并按实际回调结果选择 `success`、`info`、`warning` 或 `error`。说明影响范围及可用的下一步，按[临时通知](../components/index.md#临时通知)规范保留当前焦点，同一回执只播报一次。
* **SHOULD**　持续需要查看或处理的信息留在所属区域。重要警告与失败保留到用户处理或状态变化，多个来源分别标明作用范围。
* **MAY**　按严重度配置通知时长、关闭与操作入口。窄区允许消息换行并保留必要操作。
* **EXCEPTION**　确实需要先处理的故障可提升到页面层或有明确确认规则的对话框。

## C10 加载与空状态

首次读取可使用与目标内容结构相近的骨架，局部刷新保留已可用的数据。请求结果区承担状态，本页其它部分继续提供与任务相符的上下文及操作。

* **MUST**　区分首次加载、刷新、无记录、无匹配、失败、权限不足及部分失败。说明影响范围和适用的恢复途径，权限变化后移除受限内容。
* **SHOULD**　保留区域尺寸、可用内容和既有筛选条件，避免重复播报及不必要的焦点移动。一处失败时独立处理对应区域。
* **MAY**　按数据体量使用分页、批次、按需读取或列表虚拟化，并给出真实读取进度或可操作结果。
* **EXCEPTION**　若加载或权限变化使整页业务任务无法继续，可用页面级反馈说明可用替代路径。

## C11 详情信息展示

按对象名称、标识、状态、决策摘要、字段分组与关联数据组织。主信息和历史记录有清楚的层级；长值允许自然换行。窄区按阅读顺序显示各组。

* **MUST**　标签与字段值具有清晰对应关系，分别表达缺省、不可见与实际零值。受限字段的访问和揭示由真实权限控制。
* **SHOULD**　同类字段保持对齐，关联记录与操作日志分别标明主题和时间。读取关联数据失败时保留主对象信息。
* **MAY**　按业务配置遮罩、局部分页、字段顺序和历史范围。可揭示的敏感内容告知操作对象及可见范围。
* **EXCEPTION**　严格保密情形可省略受限值及其派生信息，仅保留权限允许说明的内容。

## C12 指标与图表

每个指标提供名称、单位、口径、时间范围和数据来源，适用时标明更新时间和比较基准。图表与表格使用同一筛选口径。优先展示核心趋势，窄区以单列顺序保持标题、数值、口径和明细可读。

* **MUST**　图形提供对应可读数值、表格或其它可访问替代，颜色与走势之外保留指标含义。数据不可用时表达受影响指标和范围。
* **SHOULD**　明确比较周期，聚合时标注时间段或层级。图表局部失败时保留有用的其它指标、筛选和明细。
* **MAY**　按业务选择图形、聚合粒度和时间范围。多序列、点位交互及轴线能力以实际组件为准，支持有限时保留读数替代。
* **EXCEPTION**　持续观看的监控可使用 Fullscreen，保持可见的统计范围、关键状态和退出入口。
