# 后台页面区域与模板

在 [全局布局](global-layout.md) 的 Main 中按业务任务组合页面区域。面包屑、标题、正文和底栏沿同一 PageContainer 边界对齐。

## 区域、顺序与操作归属

| 区域 | 使用条件 | 顺序与职责 |
| --- | --- | --- |
| Breadcrumb | 有需要说明的多级层次 | 标明祖先和当前页。显示时在全局顶栏下方独立吸顶，窄区按内容换行并占位。 |
| PageHeader | 每一页 | 呈现页名、必要的说明或对象状态，以及影响整页的主要操作。页头随正文滚动。 |
| ContextNavigation | 有同级视图或设置分类 | 位于所控制内容之前，并标明当前项。 |
| FilterRegion | 需要搜索或收窄结果 | 位于结果之前，包含查询、重置及已应用条件。 |
| ContentSection | 每一页 | 承载任务所需信息。按语义拆分同级模块，模块自身承担局部反馈。 |
| DataToolbar | 数据集可导出、选取或调整列 | 紧邻对应结果的上方，显示所选范围和批量操作。行级操作留在所属记录。 |
| Pagination | 结果分为多页 | 位于所属数据集之后，显示总体和当前页。 |
| PageActionBar | 页面存在保存、取消、分步推进或最终提交 | 在主任务末尾贴住主区可视底边，按实际高度占位。 |
| ContextPanel | 可选的解释、摘要或辅助信息 | 宽主区可放在主内容旁，窄主区排在相关主任务之后。 |

Default 密度下页标题使用 `--text-2xl`（`24px`），描述使用 `--text-sm`（`14px`）。标题与描述用 `--layout-heading-body-gap`（`8px`），面包屑与标题用 `--layout-stack-gap`（`16px`），页头与正文以及同级内容模块用 `--layout-section-gap`（`24px`）。Card 内边距沿用其配方的 `--card-spacing`，普通和小号默认分别为 `16px`、`12px`。Field 内部间距及 TableCell 垂直内边距为 `--spacing × 2`（`8px`）；表格行高由实际内容和控件决定。提交型操作栏默认基准高度为 `--spacing × 16`（`64px`），空间不足时换行增高。

## T01 列表管理页

用于查找、比较和处理一组同类记录。选用 Standard，列对照任务使用 Wide。按页头、筛选、数据工具栏、表格、分页排列。页头承担新建，筛选区承担查询和重置，工具栏承担按选择或条件执行的操作，单条动作跟随该记录。切换条件后回到第一页，明确已选数量、选择范围和总体记录数。小于 `768px` 的主区纵向重排筛选、工具栏及分页，横向滚动限制在宽表内部。表格与查询遵循 [通用组件与交互](components.md)。

## T02 详情展示页

用 Standard 呈现一个对象的身份、状态、唯一标识、主要操作和关联数据。先显示决策所需摘要，再以详情分组承载标签、字段值和长文本，最后展示有关记录或历史。同级且各自完整的视图可用 Tabs，连续阅读使用分区。主区较窄时按摘要、字段、关联内容逐段排列；空间足够时，语义一致的短字段可成对并排。关联内容的状态与对象自身维持各自范围。

## T03 表单编辑页

用 Focused 创建或修改对象。页头声明编辑目标，正文按任务顺序分组，持续显示字段标签、要求及说明，底部统一承载保存与取消。滚动到表单末尾时，最后一个字段、说明、反馈及焦点指示均须在操作栏上方完整可见。说明当前草稿或已保存状态，对有修改的退出提供可返回的处理路径。字段问题靠近对应控件，提交反馈保持输入可恢复。窄主区按阅读顺序单列；宽主区仅将关系清晰的短字段并排，长文本和复杂输入占整行。

## T04 数据仪表盘

用 Standard 呈现较简单的概览，用 Wide 呈现多个指标或并列图表。按业务目标、全局筛选、关键指标、主要图表、支撑明细组织。范围、单位、更新时间和口径应可读，筛选同步影响指标、图表和明细。按决策价值分配图表空间，窄主区优先单列并保留必要单位和同口径数据。持续观看的监控适用 Fullscreen，提供退出并恢复先前导航。

## T05 系统设置页

用 Focused 承载字段配置。页头说明影响范围，分类导航标识当前分类，设置项按影响对象及用途分组，保存和变更反馈位于操作区。显式保存时说明未保存状态，即时配置说明生效时机。危险变更使用独立区域和确认步骤。主区较窄时分类在内容之前，空间允许时可以并排；字段和说明沿相同边界对齐。

## T06 分步向导页

用 Focused 解决有顺序依赖的任务。页头说明整体结果，进度明确步骤顺序和当前项，主体呈现当前输入，底栏提供上一步、下一步和最终提交。推进前校验当前步骤，回退保留输入；确认页按顺序列出实际范围、数量及影响，完成后报告结果。窄主区按进度、内容、操作纵向排布，宽主区可并排布置进度与内容并保留可读宽度。

## 规范等级

| 等级 | 要求 |
| --- | --- |
| MUST | 页面具备有明确用途的页头及内容区。面包屑与底部操作栏显示时沿用全局吸顶和贴底规则，保持正文首尾和键盘焦点可见。按操作的影响范围确定位置，字段、数据和步骤的反馈各自可定位。 |
| SHOULD | 以主要任务选择模板和宽度模式。按业务优先级重排窄屏内容。 |
| MAY | 按权限提供导出、列配置、分类视图和辅助上下文。低风险设置可即时保存并说明触发和结果。 |
| EXCEPTION | 连续日志可使用连续加载并写明当前位置和暂停方式。对照型详情或表单可扩大内容宽度。分支向导说明需要重新确认的范围。 |

| 模板 | MUST | SHOULD | MAY | EXCEPTION |
| --- | --- | --- | --- | --- |
| T01 | 按作用范围区分整页、数据集和行级操作。 | 搜索后回到第一页，同时显示总体和当前位置。 | 按权限加入列设置或导出。 | 连续日志说明浏览范围和暂停方式。 |
| T02 | 标明对象身份，并让局部请求失败保留可用字段。 | 同类字段聚合，保护连续阅读和长文本。 | 完整的关联视图可用 Tabs。 | 媒体或数据对照任务可用 Wide。 |
| T03 | 保存放在操作栏，字段反馈有明确归属并保留其它输入。 | 标明未保存修改，优先以单列建立顺序。 | 关系紧密的短字段可双列呈现。 | 并排对照型编辑可扩大宽度，仍按组保持顺序。 |
| T04 | 指标明确范围、单位和口径，图形有可获取的实际数值。 | 先展示最重要的指标，各模块共享已生效条件。 | 展示比较、分组或趋势解释。 | 持续监控可用 Fullscreen，退出需恢复上下文。 |
| T05 | 显示配置范围和变更结果，危险动作经过明确确认。 | 按影响分组并标明当前分类与未保存状态。 | 低风险配置可即时保存并反馈。 | 启用审批的配置可以提交审批，说明生效时机。 |
| T06 | 标明当前步骤并按步校验，回退保留输入，提交后有结果。 | 一步解决一个明确问题，确认阶段概括影响。 | 长流程可提供草稿与分组进度。 | 条件分支可改变后续步骤，标明要重新确认的数据。 |
