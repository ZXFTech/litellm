# 后台页面参考

订单运营工作区由七个页面组成。Base（`base`）与朝夕（`zhaosie`）共用页面实现，主题与密度由工作区外壳传递给组件。将下列路由中的 `[theme]` 换成主题标识，可在运行中的 ForAI 查看示例。

先按[全局布局](global-layout.md)设置滚动区和外壳，再按[页面区域与模板](page-templates.md)选择页面结构，最后采用[通用组件与交互](components.md)规则。各页完整实现见[工作区源码参考](workspace-source.md)。

## 路由与页面结构

| 页面与 ForAI 路由 | 模板与容器 | 页面结构及主要组件 |
| --- | --- | --- |
| 经营概览 `/[theme]/template/admin` | T04 · Wide | 页头、统计时段和销售渠道、关键指标 Card、金额与订单数 Chart、渠道明细 Table、最近订单。页头可进入全屏监控或发起出库。 |
| 订单管理 `/[theme]/template/admin/orders` | T01 · Standard | 面包屑、页头与新建入口、订单筛选、数据工具栏、订单 Table、分页。批量处理和 CSV 导出作用于相应选择或查询范围。 |
| 订单详情 `/[theme]/template/admin/orders/detail?order=<订单编号>` | T02 · Standard | 面包屑、对象编号与状态、操作入口、订单摘要、关联信息和处理记录 Tabs。 |
| 新建与编辑订单 `/[theme]/template/admin/orders/form`，编辑使用 `?order=<订单编号>` | T03 · Focused | 面包屑、页头、订单与客户、商品项目、配送信息、页底取消与创建或保存。字段使用统一表单控件及字段校验。 |
| 工作区设置 `/[theme]/template/admin/settings` | T05 · Focused | 影响范围、基本资料／出库规则／业务通知分类、配置分组及底部保存区。危险操作单独确认。 |
| 出库向导 `/[theme]/template/admin/workflows` | T06 · Focused | 步骤导航、待出库订单选择、仓库与承运商、确认范围、底栏步骤操作和完成页。 |
| 经营监控 `/[theme]/template/admin/monitor` | T04 · Fullscreen | 保留与概览共享的统计筛选、指标、图表及明细。退出监控可回到概览并恢复原有上下文。 |

从订单列表可进入示例订单的详情和编辑页面。表单、设置和向导沿用统一吸底操作栏。面包屑显示时在顶栏下方吸顶。窄屏按阅读顺序重排，宽表在表格区域内横向滚动。

## 演示场景

各页使用共享 `Select` 在「常规」「加载中」「空数据」「错误」之间切换。加载中用于观察首次读取的布局，保持到手动切换。`Skeleton` 匹配对应区域结构，`Spinner` 与可见状态文字配对，忙碌区域标记 `aria-busy`。一次性操作回执使用共享 Toast，需要持续处理的问题留在对应区域。

| 页面 | 加载中 | 空数据 | 错误 |
| --- | --- | --- | --- |
| 经营概览与经营监控 | 指标、趋势、渠道与最近订单呈现骨架。筛选和页面操作仍可使用。 | 统计区说明当前范围无订单。 | 仅金额趋势失败，可单独重试。订单数、筛选和其他统计保留。 |
| 订单管理 | 表头和筛选保留，表体显示骨架，依赖订单数据的操作暂停。 | 可从空列表登记首笔订单。筛选无匹配时可清除条件。 | 错误留在结果区，可按原条件重试。 |
| 订单详情 | 处理记录区呈现骨架，订单摘要和对象操作仍可用。 | 显示暂无处理记录。 | 可局部重试处理记录。 |
| 新建与编辑订单 | 用字段骨架保留表单分组和底栏，暂停提交。 | 新建可直接填写空白表单，编辑可恢复暂缺资料。 | 模拟首次有效提交失败，保留已填写内容，可重试提交。 |
| 工作区设置 | 加载当前分类配置，切回常规保留草稿。 | 业务通知分类展示无偏好。 | 保存失败保留分类内修改，可重试。 |
| 出库向导 | 当前步骤呈现骨架，保留步骤与选择，暂停推进和提交。 | 无可出库订单时可返回订单管理。 | 确认时提交失败，保留本批订单、仓库和承运商，可重试。 |

## 在宿主项目中应用

1. 根据业务任务选用 T01 至 T06，并用宿主的导航、权限、数据和接口实现实际页面。
2. 用宿主项目已接入的 ForAI 组件和主题 token 组合对应区域。按本地源码和类型核对组件 API、路径和主题入口。
3. 以实际请求的状态驱动占位、空态和错误恢复。首次读取可展示骨架，刷新时保留可用数据、筛选及用户输入。工作区的场景选择和示例台账用于本地演示。
