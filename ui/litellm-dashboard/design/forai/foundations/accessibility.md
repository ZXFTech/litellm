# 焦点、键盘与状态

适用于所有可交互控件与异步反馈。

## A11Y-1 可访问操作

保留可访问名称、标签关联、原生或基础组件的键盘行为。纯图标按钮必须有明确名称，装饰图标不重复朗读。所有键盘可操作对象有可见焦点，使用 ring；不要只移除 outline。

## A11Y-2 控件状态

处理 hover、focus-visible、disabled、展开与 invalid 状态。错误边框与错误焦点使用 destructive，错误说明关联输入且不只依赖颜色。禁用状态与实际可执行行为一致。

输入区与内嵌图标按钮共用外框焦点和错误提示，内部按钮不重复叠加描边。内部按钮获得键盘焦点时外框仍有可见提示，保留 aria-invalid、可访问名称及键盘操作。

## A11Y-3 异步和动态效果

有限操作阻止重复执行，loading 期间使用 aria-busy，结果用持续可读的 status 或 aria-live 通知。失败提供原因与可用下一步，不能吞掉拒绝或把失败当成功。取消、重置和卸载隔离迟到结果，保留任务已完成的真实效果。

尊重减少动态效果偏好，旋转加载使用 motion-reduce 对应处理。实际验证鼠标、Tab、Enter、空格、关闭恢复焦点、快速重复操作、窄屏与减少动态效果；未运行项标明 NOT RUN。
