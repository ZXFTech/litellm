# Button

适用于按钮、toggle 类按钮及页面和组合中的有限异步操作。API、尺寸选项及导入路径需要核对项目实际 Button 与配方源码。

## BUTTON-1 外观与语义

复用共享组件内置外观和尺寸，颜色与圆角来自语义变量。默认普通操作使用 type=button，提交操作明确使用 type=submit。导航保留链接语义。保留禁用兼容、状态标记和减少动态效果支持。

Nova 默认密度的文字按钮 xs / sm / default / lg 高度为 24 / 28 / 32 / 36px，字号为 12 / 12.8 / 14 / 14px，行高为 16 / 22.4 / 20 / 20px。sm 字号使用 --button-sm-font-size，行高为 1.75 倍；其他密度跟随当前 CSS。纯图标对应尺寸为 24 / 28 / 32 / 36px。default 和 lg 使用 rounded-lg，xs 与 sm 使用配方规定的圆角上限，不混入其他风格数值。

## BUTTON-2 图标与焦点

文字旁图标使用 data-icon=inline-start 或 inline-end，大小与留白由组件控制。纯图标提供可访问名称。toggle 开启时图标用 text-primary；关闭恢复原色。

焦点沿用 border-ring、ring-3、ring-ring/50。禁用操作不触发提交；需保留焦点时核对基础组件是否支持相应禁用策略。

## BUTTON-3 异步反馈

| 状态 | 展示与行为 |
| --- | --- |
| idle | 原图标与操作文案，遵循业务禁用条件 |
| loading | 按真实 Promise 显示进度，阻止重复操作，aria-busy=true |
| success / error | 恢复操作文案，结果图标分别 text-success / text-danger，清除 aria-busy，仍阻止重复执行 |
| 完成反馈 618ms 后 | 恢复原图标并解除本次禁用，其他业务禁用条件保留 |

结果颜色只作用于图标，不修改按钮容器、文字、背景或尺寸。临时回执遵循[临时通知](index.md#临时通知)规范。复制成功依据实际回调；下载只报告已触发下载。仍需查看的业务状态独立于按钮的临时图标反馈。

共享任务的按钮共同阻止重复提交，只有本次发起按钮展示进度。成功后需要自动关闭、切换详情或移除按钮时，先保留 618ms 反馈。取消、关闭和重置在 loading 与反馈期间可用，清理计时器并隔离旧结果；展示等待不会回滚已完成请求。

录音或播放等持续媒体状态使用自己的状态机，其有限保存、读取、删除和恢复操作遵循本节。不人为给真实请求增加模拟延时。
