# 组件规范索引

适用于已存在于项目中的组件及其业务组合。名称用于选择适用规范，不证明模块已安装。先定位实际组件和调用处，优先复用已有实现与内置变体。

## 通用组合

颜色、字体、高度和内部留白集中在主题与共享变体。同一行控件保持相容的尺寸，图标由所选图标库和宿主配方控制。保留 data-slot、data-size 和分组结构；组合沿用已有分区与内容边界。

控件后的按钮、计数、徽标和状态按控件本体垂直居中，上方标签及下方错误不参与该行对齐。窄屏允许换行。浮层沿用基础实现的层级和动画，不随意叠加极大的 z-index。

已启用的点击、选择、展开和导航控件，实际可点区域统一使用 `cursor: pointer`，包括能激活控件的关联标签。光标由组件自身提供，禁用或不可访问的区域不显示可点击光标。直接编辑文本、拖动和调整尺寸的区域使用各自的操作光标。

## 临时通知

临时或一次性的操作回执必须使用共享 Toast，并在实际回调返回后按结果选择主题组件的语义类型。

| 类型 | 适用结果 |
| --- | --- |
| `success` | 操作成功，例如保存完成、读取恢复或下载已发起。 |
| `info` | 非阻塞的补充信息或状态告知。 |
| `warning` | 部分完成，或结果需要留意。简述限制和可用的下一步。 |
| `error` | 操作失败。说明失败的动作，并在适用时提供重试或恢复路径。 |

按回调能够确认的范围写文案，例如浏览器发起下载时写「已发起下载」。外部链接由浏览器处理时，用 `info` 提示链接已交给浏览器。Toast 保留当前焦点，同一回执只播报一次。需要持续查看或修正的字段错误、局部读取失败、权限问题与业务状态留在对应区域。

## 下拉选择

界面中用于选择预设选项的下拉选择器统一复用 ForAI `Select`，由共享组件渲染触发器和展开列表，并跟随当前主题。迁移时保留可访问的标签、说明、必填、禁用、选中值和键盘行为。搜索型输入和操作菜单继续采用各自的交互组件。
