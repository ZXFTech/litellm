# 其他基础控件

适用于 Badge、Checkbox、Switch、ToggleGroup、Tabs、Pagination。

## CONTROL-1 共享实现

复用当前基础组件与内置选项，保留 data-slot、data-size、分组和状态属性。选择状态、半选状态、禁用状态、展开状态与实际值一致。状态说明不能只依赖颜色，纯图标操作有可访问名称。

## CONTROL-2 组合与导航

同一行保持高度、字号和图标相容，Badge 与状态文字按控件本体居中。Tabs 的触发项保留所属列表与内容关系，切换不意外清空独立业务状态。全局密度的单选设置不能被取消为空值，其他选项的空值行为核对项目当前要求。

分页和导航保留实际链接或按钮语义。键盘能操作选项、开关、标签页及分页，选中与焦点提示可见。窄屏允许换行或重排，当前页面和禁用状态与实际操作一致。
