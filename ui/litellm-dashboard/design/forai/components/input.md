# 字段与输入

适用于 Input、Label、InputGroup、FileInput、Combobox 及已有项目中的同类字段。

## INPUT-1 字段关系

输入有可访问标签。错误使用 aria-invalid 并关联可读说明，禁用语义与实际行为一致。输入、尾部操作和状态按控件本体对齐，标签和错误位于控件行之外。窄屏允许重排，输入可以收缩，不撑开容器。

## INPUT-2 组合与样式

使用共享实现的分组和子组件，不复制一套字段外观。颜色、字号、高度、圆角和内部间距沿用当前主题与风格。保留焦点、invalid、disabled 和文件输入等真实状态。

组合输入的外框统一承载焦点与错误，内嵌按钮获得焦点时仍可见。FileInput 保留真实文件选择行为与名称，不能只呈现可点击外观。Combobox 的选项、查询、选择与展开行为从本地实现核对，保留键盘操作和浮层主题。

本页不定义完整 props。项目修改类型或补装组件后，下次任务读取当前源码和调用处，不重建规范或入口。
