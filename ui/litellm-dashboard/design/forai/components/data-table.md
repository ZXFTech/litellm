# 数据列表

适用于项目已有的表格、筛选和编辑组合。这份规则不代表存在可安装的独立 DataTable API。

## TABLE-1 内容与身份

优先复用已有列表。记录使用稳定 ID，排序、筛选、分页和刷新不能将选择、草稿或保存结果关联到另一条记录。列显隐变化后，占位及编辑行与可见列数一致。

## TABLE-2 状态与恢复

区分首次加载、正常数据、后台刷新、真正空列表、筛选无结果、首次失败、权限不足及单行保存失败。后台刷新和保存失败保留允许显示的旧内容与未保存输入，错误尽可能局部化，并提供明确下一步。

权限被拒绝时隐藏受限记录、编辑内容及派生反馈。网络失败不伪装成空列表，单行错误不替换整页。重试不重复提交，取消或卸载隔离旧回调。

## TABLE-3 可访问性与布局

进度提供可访问提示，错误关联输入且持续可读。选择、排序、菜单和恢复操作支持键盘。卡片内的表格不通过新增横向滚动、裁切文字或隐藏字段规避窄屏布局，具体见 [卡片布局](../layout/card.md)。
