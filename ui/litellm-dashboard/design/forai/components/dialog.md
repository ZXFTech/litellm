# 浮层与对话框

适用于 Dialog、AlertDialog、Drawer、Popover、HoverCard 及其业务组合。

## DIALOG-1 语义与行为

对话框提供标题与必要说明，允许使用视觉隐藏标题但保留可访问名称。触发器、关闭、确认及取消使用当前基础组件的组合结构。保留键盘操作、焦点管理及关闭后恢复焦点。

确认、保存等有限操作遵循 [Button 异步反馈](button.md)，不能让取消被 loading 状态一并禁用。失败保留用户输入与可恢复上下文。

## DIALOG-2 主题与边界

浮层使用 popover、muted、border 和 ring 等当前语义变量，保留现有层级与减少动态效果处理。根主题与密度覆盖 Portal。局部容器主题的 Portal 隔离需要项目单独设计和验证。

常规宽度与窄屏下内容、操作和焦点提示完整可用，长内容允许必要的纵向滚动。核对明暗、三档密度、打开、关闭、Tab 和 Escape 的实际结果，不能用源码存在代替交互证据。
