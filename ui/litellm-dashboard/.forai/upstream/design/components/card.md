# Card：卡片通用规范

适用于普通内容卡片、交互演示卡片，以及设置、预览等卡片型浮层。

## 横向布局

* 页面或容器的通用溢出策略仍须遵守本节对卡片及其内部内容的边界约束。
* 所有卡片及其内部内容区域均不得出现横向滚动或横向滚动条。文本、表格、代码及控件组合通过换行、缩放到可用宽度或响应式重排完整展示，不增加内部横向滚动区。
* 卡片宽度受父容器和视口可用宽度约束。flex / grid 子项按需设置 `min-w-0`、`max-w-full`，同一行空间不足时换行或改为纵向排列。
* 长链接、标识符等连续文本允许在任意位置换行，例如使用 `wrap-anywhere`；控件按可用宽度收缩或重排，不能让固定宽度、最小宽度或 `whitespace-nowrap` 撑出卡片。
* 核对伪元素、负外边距、扩展点击区域及焦点提示的实际边界，确保落在卡片可用空间内；不要只检查可见元素的宽度。
* 优先修正溢出来源。`overflow-x-hidden` 可用于边界防护，但不能仅隐藏滚动条或裁掉正文、操作和焦点提示来满足规范。高度受限时可保留纵向滚动。

## 验证

* 在真实浏览器中检查常规宽度与窄屏、三档布局密度、明暗主题、长连续文本及交互状态，卡片和内部内容区均无横向滚动。
* 结合实际内容确认 `scrollWidth <= clientWidth`，检查伪元素与扩展点击区域；没有可见滚动条但内容仍溢出或被裁切，不算通过。
* 验证换行与重排后文字和控件完整可用，点击、键盘焦点及必要的纵向滚动保持正常。
