# Layout：页面布局与示例规范

本文件维护页面布局决策及布局示例的展示要求。通用页面遵循“页面布局决策”；以下“示例展示与实现”、间距标注、开关及标注验证仅适用于布局示例与规范展示。具体页面要求按下级入口读取。

## 页面布局决策

* 先明确页面主要任务、核心操作和信息顺序，再划分导航、工具栏、主内容与辅助区域；每个区域承担明确职责，复用现有布局外框与共享组件。
* 明确区域宽度如何分配：固定、随内容、自适应伸展或限制阅读宽度；根据实际容器可用空间组织内容，避免只针对单一视口尺寸排版。
* 明确页面与各区域的滚动归属、固定或粘性区域及内容溢出策略。确保正文、操作和焦点提示可达。
* 窄屏按任务优先级重排、折叠或转为浮层，保留必要操作入口与合理阅读、键盘顺序；布局切换保留输入、选择及任务状态，焦点所在内容被收起时将焦点转移到可用的对应入口。
* 在代表性的宽屏、窄屏和长内容下验证区域伸缩、滚动归属、固定区域遮挡及布局切换后的操作可达性；复用任务已有验证，记录实际检查结果。

## 示例展示与实现

* 复用已有文档外框、语义主题和共享组件；布局示例复用全局密度 token，并保留明确的标注作用域。
* 同级布局使用 flex / grid 与 gap。分别核对区块间距、横向间距、文字层级、内容内边距和元素外边距。
* 规范逐项标出实际消费的 CSS token 名称、取值和作用范围；工具类是 token 的使用方式，不能代替 CSS token 名称。
* 明确区分上游变量、项目语义映射和固定值；没有对应变量的固定值如实说明，不虚构 token。
* 密度切换通过真实 CSS 属性改变间距、字体、行高及控件尺寸，不通过 zoom 或 transform 缩放界面。
* 组合组件保留统一内容边界；全局密度 token 在文档根元素维护，Portal 自动继承；布局示例需要局部作用域时显式接收当前全局密度。
* 字号和尺寸的实际值集中在应用主题 CSS 中维护，规范与示例按同一组 token 对照，避免逐页覆盖共享组件内部样式。

## 间距色带与 token 标注

后续布局示例统一提供可开关的间距标注，复用主题 CSS 中的语义变量及明暗取值：

| 类型 | 色带与纹理 | 语义变量 |
| --- | --- | --- |
| padding | 蓝色，实色 | `--spacing-guide-padding` / `--spacing-guide-padding-foreground` |
| margin | 橙色，斜纹 | `--spacing-guide-margin` / `--spacing-guide-margin-foreground` |
| gap | 紫色，竖纹 | `--spacing-guide-gap` / `--spacing-guide-gap-foreground` |

* 同时提供文字图例和同色 token 标签，不只依赖颜色。标签靠近对应示例，写出实际消费的完整 CSS token 名称；区分 inline / block，必要时说明 `--spacing × 倍数`。固定值注明数值及“无对应 CSS token”，不虚构变量。
* 色带根据当前 computed style 与元素实际位置绘制，随密度、尺寸、换行和滚动更新。使用真实 padding / margin / gap，不为画图插入占位间隔；零外边距不画色带，折叠外边距与负外边距如实说明，不把负值画成正的留白。
* 标注层采用不参与排版的覆盖方式，设置 `pointer-events: none` 和 `aria-hidden="true"`；保证子元素负外边距、滚动裁剪及小数像素不会使色带侵入内容、扩大滚动区域或产生额外滚动条。
* 颜色说明、CSS token 名称和固定值说明统一放入受开关控制的标注区域，正常示例正文使用不依赖色带的文案，避免关闭后残留裸 token 或指向不存在的色带。

## 「显示间距标注」开关

* 在布局示例页的标题操作栏使用共享 Switch，文案为“显示间距标注”，默认开启；提供关联标签、可访问名称、键盘操作与焦点提示。
* 关闭后同时隐藏色带、token 标签（含字号、行高及固定值说明）与图例，收起标注自身占用的空间；使用规范中的 token 和来源继续展示。
* 标注显隐与密度选择独立：切换开关保留当前密度及示例真实字号、行高、内外边距，保留 Tabs、输入、选项和分页等交互状态。
* Portal 浮层同步接收同一标注显隐状态及标注样式作用域；不能只依赖页面 DOM 祖先选择器。
* 关闭时卸载覆盖层并清理观察器、事件监听及待执行的重测任务；重新开启后按当前布局重新测量绘制。

## 标注验证

* 核对三档密度、明暗主题及窄屏换行下的实际间距与色带；同一类间距的颜色、纹理和 token 标签保持一致。
* 验证初始开启、点击开关、空格键及点击标签，反复开关后布局尺寸与交互状态保持；关闭时示例与浮层中没有可见的 token 标注，规范内容不被隐藏。
* 检查浮层滚动、外边距折叠和负外边距场景；标注不遮挡文字、不阻碍点击、不引入溢出或额外滚动条。
