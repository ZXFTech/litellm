# ForAI 项目入口草案

这是待审阅的补丁内容，不是已生效的 Agent 文件。按项目要求做模型审阅后，在既有根 AGENTS.md 中展示精确差异，由操作者明确应用，保留原有指引。项目尚无 AGENTS.md 时，也先审阅新建草案。

建议加入以下通用短入口：

```markdown
## 组件与样式

涉及组件、样式或布局的开发、检查和调整时，先读取 [当前项目设计规范](design/forai/index.md)，再按索引读取本次适用文档。重新读取当前文件，不使用聊天记忆或旧报告代替。组件是否存在、真实 API 和导入路径以本地源码、类型及项目配置为准。缺失链接、含糊或冲突的要求应明确报告。只读检查不修改项目文件；调整任务按授权范围修改实现并复查。

入口缺失、工具读取失败或文件核对不完整时，最终报告将无法确认的项明确标为 BLOCKED，列出实际路径、失败原因和证据缺口；其余范围按已有证据分别报告。没有完整前后内容证据，不声明全项目零新增、零修改、零删除；未主动编辑与已证明内容未变分开报告。
```

入口只引用后代规范路径，不将组件局部规则提升到根指引。普通规范编辑、补装组件和 API 修改不需要复制正文或重建入口。
